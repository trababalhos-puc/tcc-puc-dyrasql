# Data

Esta pasta contém dados utilizados nos experimentos do DyraSQL.

## Conteúdo

- Scripts SQL de inicialização
- Amostras de dados para testes
- Datasets sintéticos

## Nota

Arquivos grandes (CSVs, Parquet, JSON) estão no `.gitignore` e não são versionados.
Para reproduzir os experimentos, execute os scripts de geração de dados disponíveis em `src/`.
