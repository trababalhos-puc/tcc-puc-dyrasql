DyraSQL - Documentação
======================

**DyraSQL** é um framework para roteamento dinâmico de consultas SQL baseado em metadados de tabelas Apache Iceberg.

O sistema direciona automaticamente consultas para clusters Trino de capacidades distintas, otimizando o uso de recursos através da análise de metadados obtidos via comando EXPLAIN (TYPE IO).
